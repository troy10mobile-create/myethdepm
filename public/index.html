Exchange V2 — Foundation

Sepolia testnet only.

This milestone establishes the PostgreSQL account and wallet registry foundation. It does not yet process deposits, sweep funds, execute withdrawals, or distribute fees.

Available API

Health: /healthz

Configuration: /api/config

Registration, login, session and request endpoints are documented in the project README.

Do not send funds to addresses generated by this foundation until the transaction-processing stage is deployed and verified.
